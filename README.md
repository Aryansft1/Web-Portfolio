# 🌐 مجموعه پروژه‌های Frontend (HTML / CSS / JavaScript)

---

## 👨‍💻 درباره این ریپوزیتوری

این ریپوزیتوری شامل مجموعه‌ای از **پروژه‌های تمرینی و عملی در حوزه Frontend Development** است که با استفاده از **HTML, CSS و JavaScript** ساخته شده‌اند.

هدف این مجموعه، تقویت مهارت‌های طراحی رابط کاربری (UI)، تعامل با DOM و ساخت پروژه‌های واقعی وب است.

---

## 🚀 تکنولوژی‌های استفاده شده

- 🌐 HTML5
- 🎨 CSS3 (Flexbox, Gradient, Glassmorphism)
- ⚙️ JavaScript (Vanilla JS)
- 💡 DOM Manipulation

---

## 📚 پروژه‌های موجود

### 💥 1. Smart Dashboard (پروژه اصلی)
- 🌙 Dark / Light Mode
- ⏰ ساعت زنده (Live Clock)
- 📝 سیستم To-Do ساده
- 🎨 طراحی Glassmorphism
- ✨ انیمیشن‌های hover

---

### 🧮 2. (پروژه‌های آینده)
- ماشین حساب حرفه‌ای
- فرم لاگین (Login UI)
- سایت فروشگاهی (Landing Page)
- Weather App با API
- Portfolio شخصی
