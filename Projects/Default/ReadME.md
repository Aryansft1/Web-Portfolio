# 🚀 Smart Dashboard Pro (HTML / CSS / JS)

---

## ✨ توضیح پروژه

این پروژه یک **داشبورد مدرن و تعاملی** است که با استفاده از HTML, CSS و JavaScript ساخته شده و شامل یک UI شیشه‌ای (Glassmorphism) و امکانات ساده مدیریتی است.

---

## 🎯 ویژگی‌ها

- 🌙 حالت تاریک و روشن (Dark Mode)
- ⏰ ساعت زنده (Live Clock)
- 📝 سیستم To-Do ساده
- 🎨 طراحی مدرن Glassmorphism
- 🌈 پس‌زمینه گرادینت
- ✨ انیمیشن hover روی کارت‌ها و دکمه‌ها

---

## 🛠️ تکنولوژی‌ها

- HTML5
- CSS3 (Flexbox + Gradient + Glass UI)
- JavaScript (Vanilla JS)
